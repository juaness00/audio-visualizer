# audio-visualizer

Interactive audio visualizer that turns music into customizable real-time
visuals — driven by frequency, color, shape, and sensitivity controls.

## Status

Early scaffold. See the Linear project for the tracked backlog.

## Stack

- Vite + TypeScript
- Web Audio API (`AnalyserNode`) for FFT frequency data
- Canvas 2D renderer

## Development

```bash
npm install
npm run dev
```
